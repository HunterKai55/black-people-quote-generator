# Quote Generator

A simple web application that displays a random quote whenever the user clicks the **New Quote** button.

## Features

* Generates a random quote
* Displays the quote dynamically
* Displays the corresponding author
* Changes the background image with each new quote
* Simple and responsive user interface
* Interactive button using JavaScript

## Technologies Used

* HTML
* CSS
* JavaScript

## How It Works

The application stores a collection of quotes, authors, and corresponding images in JavaScript.

When the user clicks the **New Quote** button, JavaScript randomly selects an entry from the collection and updates the quote, author, and image on the page.
